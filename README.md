# v3

Deep learning studied from first principles up to training small language models, one topic at a time, with code that runs.

## Plan

1. Foundations: *Understanding Deep Learning* (Simon J. D. Prince) and *Mathematical Introduction to Deep Learning* (Jentzen, Kuckuck, von Wurstemberger)
2. Autograd and neural networks from scratch (micrograd, makemore)
3. Transformers and GPT (nanoGPT)
4. Tokenization (minbpe)
5. GPU programming with CUDA C++
6. Training a modern LLM end to end
7. Chat models, fine-tuning and inference
8. AI engineering: retrieval, tools, evals
9. Automated experiments
